# Glucovibes-Posts

Publicaciones para Instagram y LinkedIn de Glucovibes, generadas a partir de las newsletters.

Cada carpeta `NN_tema/` contiene:
- `post.json`: contenido (slides, textos de Instagram y LinkedIn, fecha sugerida, estado)
- `slide_XX.png`: carrusel final 1080x1350 (Instagram)
- `carrusel.pdf`: el mismo carrusel en PDF (LinkedIn)
- `slides.html`, `curvas.png`: fuentes del render

Las imágenes se sirven desde `raw.githubusercontent.com` para subirlas a Buffer.
